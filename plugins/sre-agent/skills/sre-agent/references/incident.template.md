# Incident file + index templates

Copy the incident skeleton to `docs/sre-incidents/<YYYY-MM-DD>-<slug>.md` and
prepend a row to `docs/sre-incidents/INDEX.md`. No secrets — metadata only.

## INDEX.md (create on first capture, newest first)

```markdown
# Incident Index — <project/repo>

_Generated by sre-agent. No secrets — metadata only._

| Date | Service | Env | Symptom class | Signature | Root cause | Fix | File |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| <YYYY-MM-DD> | <service> | <env> | <class> | <signature> | <root cause> | <fix> | [↗](<YYYY-MM-DD>-<slug>.md) |
```

## Incident file skeleton

```markdown
# <service> — <symptom> (<YYYY-MM-DD>)

Service: <name> · Env: <cluster/ns> · Symptom class: <class> · Outcome: resolved
Signature: <key error/metric fingerprint>

## Symptom

<what was observed — impact, when it started>

## Root cause

<the confirmed cause>

## Evidence

- [<source command/query>] <decisive fact>

## Fix applied

<validated remediation (commands / GitOps change)> · Rollback: <how to revert>

## Validation

- <expected-behavior criterion> → pass

## Ruled out

- <hypothesis tried and disproven>

## Links

- <dashboards / PRs / repos / runbooks — no secret values>
```
