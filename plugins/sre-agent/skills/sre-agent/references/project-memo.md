# Project Context Memo

Phase 0 reads this to warm-start; Phase 2 writes it back at end of run. The memo
lives at `docs/sre-agent-memo.md` in the repo the agent is invoked in. It is a
**curated, service-centric** distillate of discovery — durable structure only,
never a full object inventory (those stay a live `kubectl get` away).
Everything the memo records is metadata; **never a secret value**.

## Memo schema

```markdown
# SRE Agent Memo — <project/repo name>
_Last verified: <YYYY-MM-DD> · Generated by sre-agent. No secrets — metadata only._

## 1. Environments
| Env | Cluster / context | Cloud acct | Region | Key namespaces | Notes / limitations |

## 2. Observability
| Component | Access (svc / port-forward cmd / URL) | Auth source | Status |
Components: Prometheus, Alertmanager, Grafana, Loki, Tempo/Jaeger,
Elasticsearch/OpenSearch, CloudWatch.
"Auth source" = pointer only (e.g. "token in Vault kv/obs/grafana",
"AWS Secrets Manager arn:…"). "Status" = ✓ verified <date> | ⚠ needs verification | ✗ not present.

## 3. Service map
### <service>
- Namespace / Deployment / Service / Ingress-or-endpoint
- Dashboards · Alerts · Log source (LogQL/index) · Traces
- Repo · CI/CD pipeline
- Owner / dependencies

## 4. Changelog
- <date> — <structural change> (new/removed workload, image bump, ingress/ns/ownership/dep change, obs link change)

## 5. Discovery history
- <date> — scanned: <scope> · reused: <what> · changed: <what> · needs verification: <what>

## 6. Known unknowns
- <fact marked needs-verification> — why (no access / ambiguous / not yet investigated)
```

Two rules keep it high-signal:

- **Section 3 grows by investigation, not by cluster scan.** A service enters
  the map the first time the agent works on it — not by enumerating everything.
- **Every §1/§2 row carries a `Status` marker.** The freshness check reads and
  stamps these, so "verified vs assumed" is never guesswork.

## Fast freshness check

Cheap, read-only, bounded. Proves what still exists without full re-discovery.
Best-effort: if `kubectl` or an endpoint is unreachable, mark the fact
`⚠ needs verification` — **never delete on a single failed check**.

| What | Command | Pass = |
| :--- | :--- | :--- |
| Clusters/contexts | `kubectl config get-contexts -o name` | memo context still listed |
| Namespaces | `kubectl get ns <memo-namespaces>` | namespace still exists |
| Service-map workloads | `kubectl get deploy,sts,ds -n <ns> <names>` | present; note if image tag changed |
| Obs endpoints | readiness probe from `discovery.md` (`/-/ready`, `/api/health`, `/ready`) against the recorded access path | probe returns healthy |

Stamp each fact: pass → `✓ verified <today>`; fail → `⚠ needs verification`,
add to §6 Known unknowns, and route it to Phase 2 for real re-discovery.

## Update rules (Phase 2 write-back)

- **Add** newly discovered structure and any service investigated this run to §3.
- **Verified change** (image bump, new/removed workload, ingress/namespace/
  ownership/dependency change, obs-link change) → update the row **and** append
  one §4 Changelog line.
- **Failed verification** → mark the row `⚠ needs verification`; **do not
  hard-delete**. Remove a fact only once it is confirmed absent (explicitly
  gone), not after a single miss.
- Append exactly one §5 Discovery-history line per run.
- **Verified information only.** Anything inferred but unconfirmed is written
  as `needs verification`, never as fact (the "never guess" rule, applied to the memo).
- Update the `_Last verified:_` date. Write the file, then commit it locally
  (`git add docs/sre-agent-memo.md && git commit`); **never push, never add a
  co-author line**. If the working dir is not a git repo, write the file and
  note that it was not committed.

## Edge cases

| Case | Behavior |
| :--- | :--- |
| No memo yet | Cold start — create fresh from `project-memo.template.md`. |
| No cluster access | Memo still usable as hints; mark everything `needs verification`; no deletions. |
| Multiple environments | One memo, per-env rows in §1. |
| Corrupt/unparseable memo | Copy it to `docs/sre-agent-memo.bak.md`, warn, start fresh. |
